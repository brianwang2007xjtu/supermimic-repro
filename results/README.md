# 结果数据

所有数据由 44,000 次迭代的检查点在 LAFAN1 的 40 条动作上产生。训练在单张 RTX 4090（24 GB）上完成，2048 个并行环境，批大小 2048，锚点观测开启。

## 文件

| 文件 | 内容 |
| --- | --- |
| `training_series.csv` | 每 50 次迭代一行：迭代数、训练时长、吞吐、训练回报、世界模型 1 步与 8 步误差、想象回报与存活率、仿真/世界模型/策略三阶段耗时 |
| `tb_scalars.csv` | TensorBoard 全部标量导出（37 个 tag，13,801 个点），含 `wm/*`、`policy/*` 系列 |
| `bench_by_ckpt.csv` | 11 个检查点在固定 4 条动作（dance1_subject1、walk1_subject1、jumps1_subject1、fallAndGetUp1_subject1）上的 benchmark |
| `per_clip_eval.csv` | 最终检查点在全部 40 条动作上的整段评测：步数、时长、归一化回报、是否触发终止 |

## 列说明

`training_series.csv`

- `iteration`：环境步数，等于训练迭代数
- `train_ret`：训练回合的归一化回报
- `wm_nse1` / `wm_nse8`：世界模型的 1 步与 8 步开环预测误差（按论文的名义尺度归一化；最后 1 万次迭代均值分别为 0.009 与 0.018）
- `imag_ret` / `imag_surv`：想象轨迹的累计奖励与存活率
- `t_sim_s` / `t_wm_s` / `t_policy_s`：每 50 次迭代中仿真、世界模型训练、策略训练各自耗时

`per_clip_eval.csv`

- `norm_return`：逐步奖励之和除以 0.1×步数，1.0 表示完美跟踪
- `failed`：是否在片段结束前触发终止条件（根高或倾角超限）

## 汇总

固定 4 条动作的 benchmark 随迭代的变化：

| 迭代 | 回报 |
| --- | --- |
| 4,000 | 0.449 |
| 8,000 | 0.590 |
| 12,000 | 0.650 |
| 16,000 | 0.712 |
| 20,000 | 0.803 |
| 24,000 | 0.769 |
| 28,000 | 0.815 |
| 32,000 | 0.844 |
| 36,000 | 0.864 |
| 40,000 | 0.867 |
| 44,000 | 0.886 |

全部 40 条动作：平均 0.882，标准差 0.074，最低 0.661（fallAndGetUp1_subject4），最高 0.969。

## 复现环境

- GPU：NVIDIA RTX 4090，24 GB，驱动 580.76 / 570.124（两台实例）
- 软件：Python 3.12，torch 2.14.1，MuJoCo 3.16，MuJoCo Warp 3.16，Warp 1.18
- 训练：4.3 小时（含约 5 分钟内核编译）
